## Status meanings

- **CANONICAL** — current-state authority. Start here.
- **LIVING** — current contract/plan/reference; maintain when implementation semantics change.
- **REFERENCE** — useful design/background material that is not the primary current-state authority.
- **HISTORICAL** — audit, incident, task, old plan or chronological work record. Preserve for evidence; do not treat as current state.

Current-state precedence:

1. `PROJECT_STATUS.md`
2. `docs/CURRENT_PRIORITIES.md`
3. living technical contracts
4. historical/reference material

If an old dated document contradicts the current code or canonical current-state docs, treat it as historical evidence of that point in time.
